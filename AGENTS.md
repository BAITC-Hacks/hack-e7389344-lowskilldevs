# Инструкции по проекту

## Задача
Рабочий MVP расчёта пополнения склада для кейса Электрокомплект на HackAlem AI.

## Ограничения
- Сохранять запуск `python -m streamlit run app.py` и работу без API-ключей.
- `planner.py` — вычисления, `data_loader.py` — импорт, `ai_agent.py` — объяснение проверенного результата, `app.py` — интерфейс.
- Не отправлять заказы поставщикам автоматически. Изменение данных или количеств отменяет утверждение.
- Не коммитить исходные Excel компании, клиентские данные, `.env`, ключи и токены.
- Примеры только синтетические. Сохранять ведущие нули в кодах номенклатуры.
- Не выдавать месячный остаток за точное число дней stockout, а оценку недопродаж — за фактические потери.
- Не скрывать неопределённые остатки или даты прихода заменой на достоверный ноль.
- Менять код целенаправленно; обновлять README при изменении расчёта, интерфейсов и запуска.
- Перед коммитом выполнить `python -m unittest discover -s tests -v`.
- Не добавлять базу данных, авторизацию или инфраструктуру развёртывания без отдельной задачи.
