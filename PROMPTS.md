# Работа команды

Перед изменениями прочитайте AGENTS.md. Сначала проверяйте соответствие официальному кейсу пополнения склада и существующим входным файлам.

- **Интеграция:** проверять полный сценарий от импорта двух поставщиков до утверждённого CSV; поддерживать README и демонстрацию.
- **Интерфейс:** развивать app.py, сохраняя явные допущения, редактирование количества и сброс утверждения при изменении расчёта.
- **Расчёт и данные:** развивать planner.py и data_loader.py, добавляя проверки поведения по ТЗ; не выдавать отсутствующие данные за известные.

Общие проверки перед сдачей: `python -m unittest discover -s tests -v`, запуск приложения, проверка отсутствия Excel компании и секретов в Git.
