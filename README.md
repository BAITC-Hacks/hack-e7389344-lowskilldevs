# hack-e7389344-lowskilldevs
## Hackathon team repository for LowSkillDevs

**Track/Topic:** Logistics

**Prompt of track/topic (on Russian):** Менеджер закупа считает пополнение склада в Excel, поэтому заказы выходят редко, а разовые крупные продажи портят регулярную потребность. Сервис по истории продаж, остаткам и товарам в пути предлагает заказы поставщикам и убирает разовые всплески из расчёта.

**Prompt of track/topic (on English):** The purchasing manager calculates inventory replenishment using Excel, resulting in infrequent orders, while one-off large sales distort the data on regular demand. The service analyzes sales history, stock levels, and goods in transit to suggest orders to suppliers while excluding one-time spikes from the calculations.
